Introduction

Perhaps the most important aspect of HTML is the ability to link from one document to another. This is the basic concept underlying the web, and without this functionality the World Wide Web would not exist.

Link syntax

Creating links is relatively straightforward, and the syntax provides flexibility in where and how links are applied. To create a link, use the anchor element (<a>) to wrap the content you want to make clickable. The href attribute tells the browser where the link should go. Here is an example: 

<a href="syntax.html">HTML syntax</a>

In this example, “HTML syntax” appears as a clickable link. The href attribute tells the browser where to direct the user.

Link types

Three common link types are absolute, document-relative, and site-root-relative links. Each uses the href attribute to tell the browser how to locate the destination.

Absolute links

Absolute links contain the full URL, including the protocol. They are commonly used to link to pages outside your site: 

<a href="https://www.google.com">Google</a>

Document-relative links

Document-relative links give the path from the current page to the destination page. If both pages are in the same folder, the link might look like this: 

<a href="contact.html">Contact us</a>

If the destination is in a folder below the current page, include that folder in the path:

<a href="resources/contact.html">Contact us</a>

To move up to the parent folder, use ../:

<a href="../contact.html">Contact us</a>

Site-root-relative links

Site-root-relative links start at the website’s root folder. They begin with a forward slash: 

<a href="/contact.html">Contact us</a>

If the destination is in a folder, include the folder in the path:

<a href="/resources/contact.html">Contact us</a>

Fragment identifiers

A fragment identifier links to a specific location on a page. Give the destination element an id, such as: 

<h2 id="camp">Camping</h2>

Then link to that ID using a hash symbol:

<a href="#camp">Learn more about camping</a>

You can also link to an ID on another page:

<a href="faq.html#camp">Read our FAQ on camping</a>
