Introduction

Perhaps the most important aspect of HTML is the ability to link from one document to another. This is the basic concept underlying the web and without this functionality the World Wide Web would not exist.

Link syntax

Creating links is relatively straightforward, and the syntax provides a lot of flexibility in where and how links are applied. To create a link, you’ll use the anchor element (<a>) to wrap the content you wish to convert to a link. Attributes inside the anchor tag tell the browser where the page is linking to, or point to an external resource that the browser should download. Take the following link example: 

<a href="syntax.html" title="Learn more about syntax">HTML syntax</a>

Here the text “HTML syntax” would now appear as a clickable link. The href attribute tells the browser how to resolve the link; that is, where the user should be directed when the link is clicked. The optional title attribute provides a description of the link.

Link types

There are three basic types of link: absolute, site-root relative, and document relative. Each type refers to the value of the href attribute, which tells the browser how to resolve a link.

Absolute links

These links contain the entire URL necessary to resolve a link, including the protocol. This is usually done for external links, which are links to pages outside of the current site. Here’s an example: 

<a href="https://www.google.com">Google</a>

Document relative links

These links are commonly used to navigate internally within a site. The href value gives the path from the current page to the destination page. 

<a href="contact.html">Contact us</a>

This example assumes the contact page and current page are in the same directory. If the contact page is in a directory below the current page, the link might look like this: 

<a href="resources/contact.html">Contact us</a>

To move out of a directory, use ../ before the filename: 

<a href="../contact.html">Contact us</a>

This link moves up from the current directory and finds contact.html in the parent directory. You can use more than one ../ if needed.

Site-root relative links

These links start at the root folder for the site, then move down through directories to the desired page. They begin with a forward slash (/). 

<a href="/contact.html">Contact us</a>

If the contact page is inside a directory, the link could look like this:

<a href="/resources/contact.html">Contact us</a>

Fragment identifiers

A fragment identifier links to a specific location within a page. It points to an element with a matching id attribute. For example, a heading could have this ID: 

<h2 id="camp">Camping</h2>

Link to that heading elsewhere on the same page like this:

<a href="#camp">Learn more about camping</a>

The hash symbol (#) tells the browser to look for an element with the matching ID. You can also link to a fragment on another page: 

<a href="faq.html#camp">Read our FAQ on camping</a>
